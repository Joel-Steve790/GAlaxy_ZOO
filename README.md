# Galaxy Zoo

Galaxy morphology classification project using the Galaxy Zoo 2 data.

## Dataset

The galaxy image files are not included in this repository because of their size. The images used by this project are from the Kaggle dataset [Galaxy Zoo 2: Images](https://www.kaggle.com/jaimetrickz/galaxy-zoo-2-images). Download the dataset from Kaggle and place the images in `galaxy_project/archive/images_gz2/images/` to use the local project scripts.

The Galaxy Zoo 2 Hart et al. (2016) classification catalog is available from the [official Galaxy Zoo data release](https://data.galaxyzoo.org/). Please follow the data release's citation guidance when using the catalog.
